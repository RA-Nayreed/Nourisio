# Nourisio
A machine learning project to provide personalized health recommendations and insights.

## Overview
This project aims to build an AI-powered personal health coach that provides:
- Personalized meal and fitness recommendations.
- An interactive dashboard for visualizing user progress.
- A chatbot for answering health-related queries.

## Features
1. **User Profiling**: Age, weight, activity level, and health goals.
2. **Recommendations**: Calorie needs, meals, and fitness plans.
3. **NLP Chatbot**: Health-related Q&A.
4. **Dashboard**: Calorie trends, progress tracking.
